## Geändert

- Konsolenbefehle erhalten jetzt zuverlässig einen gültigen Overworld-Kontext.
- Gepufferte Befehle werden nach dem Serverstart in korrekter Reihenfolge ausgeführt. /stop, Vanilla-, Plugin- und RCON-Befehle funktionieren vor und nach Serverstart.
- ``ÌllegalState Exception`` statt ```Nullpointer Exception``` bei ungültigen weltlosen Command-sources (Player/Server?).
- Neue Runtime-World-API-Methode ```loadWorldAsync(NamespacedKey).```
- WorldLoadResult und WorldCloneResult liefern jetzt worldKey() und worldPath().
- Neuer Fehlerstatus IDENTITY_MISMATCH bei Verwechslung von Weltname und World-Key.
- Plugins müssen für Runtime-Welten ```World#getKey()``` statt ```World#getName()``` nutzen.
- Windows-Paperclip-Langpfadtest mit Pfaden bis 251 Zeichen ergänzt. 

Beispiel Code für das Benutzen von World#getKey() über die Tessera-API

```java
NamespacedKey key = NamespacedKey.fromString(savedWorldKey);
if (key == null) {
// gespeicherte Identität ist ungültig
return;
}

runtimeWorldManager.loadWorldAsync(key).thenAccept(result -> {
if (!result.successful()) {
// result.status(), result.message() und result.cause() auswerten
return;
}

    World world = result.world();
    NamespacedKey stableKey = result.worldKey();
    Path actualPath = result.worldPath();
});
```
